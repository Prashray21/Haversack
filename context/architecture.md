# Architecture context

pnpm workspace, TypeScript ESM throughout, Node >= 20.

- `packages/core` — the engine. No CLI concerns, no fs in the hot paths:
  - `schema/` — `project.yaml` spec v1 as Zod schemas (`runtime: 1` literal,
    kebab-case ids, safe repo paths, forward-slash globs).
  - `parse/` — loads `project.yaml` + referenced context/rules files
    (BOM-stripped, LF-normalized; missing files are load errors).
  - `adapters/` — pure `TargetAdapter` implementations (generate definition →
    file bytes). Registered in `registry.ts`, one line per target. Only
    `claude-code` (root `CLAUDE.md`) exists today; cursor and copilot are
    pending (M7, docs-gated).
  - `checks/` — static pattern checks (picomatch path scoping, per-line regex)
    and the shared result types. LLM-judged checks are schema + skipped
    semantics only until the judge exists (M6).
  - `drift/` — generated-file states (`unchanged`, `stale`, `hand-edited`,
    `untracked`, `new`) against `.runtime/manifest.json` (stable JSON, sorted
    keys, trailing newline).
  - `secrets/` — hand-rolled credential-shape scanning; findings are always
    redacted; `runtime:allow-secret` line marker and `secrets.ignore` provide
    allowlisting.
- `packages/cli` — commander wiring (`runtime sync`, `runtime check`) and
  command implementations that inject stdout/stderr (no direct console in
  library code).
- `apps/github-app` — stub only; the App is out of scope for now.
- `.github/workflows/ci.yml` — test matrix on ubuntu + windows.
- `.github/workflows/release.yml` — Node SEA single-executable builds
  (linux-x64, macOS arm64/x64 ad-hoc signed, windows-x64) + SHA256SUMS.txt.

## Exit codes (D6)

0 success; 1 changes or drift detected (`sync --verify`) or a block-severity
check failure (`check`); 2 configuration error; 3 secret detected (findings
redacted).

## Invariants worth defending

- Adapters are pure: same `CompiledProject` in, same bytes out (the drift
  manifest depends on it).
- Generated files carry the `GENERATED BY RUNTIME — DO NOT EDIT` header.
- A skipped check is never a pass; budget exhaustion and unparseable judge
  output yield `skipped` with a reason.
- All hashing uses BOM-stripped, LF-normalized content.
